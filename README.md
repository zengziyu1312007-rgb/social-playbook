# 人情世故指南

**151 个生活与职场场景 · 18 个主题 · 两轮回应 · 可直接使用的 AI Skill**

朋友借钱不想借，怎么回？亲戚追问工资、催婚，怎样说得体面？领导周五通知周末加班，怎么表达边界？

**生活 48 个场景 + 职场 103 个场景**，既考虑关系，也尊重事实、已有承诺和自己的选择。

这里把难开口的问题拆成：**先确认什么 → 第一句怎么说 → 被反问后怎么接 → 接下来做什么 → 哪些情况不能硬套**。

[在线打开指南](https://zengziyu1312007-rgb.github.io/social-playbook/) · [下载完整 PDF](downloads/social-playbook.pdf) · [阅读文字版](GUIDE.md) · [下载 Skill](downloads/social-conversation.zip) · [查看来源](SOURCES.md)

## 用 PDF 提问

下载 167 页的完整 PDF，上传到豆包等支持文件的对话工具。说明实际处境，请它找对应场景，给出第一句，并根据对方的追问继续练习。PDF 含 151 个场景、可点击目录和参考资料。

## 使用网页

下载仓库后直接打开 `index.html`。页面支持关键词检索、生活/职场筛选、18 类主题筛选、内容依据筛选、分页阅读、复制回应与复制给 AI 的问题。全部内容可离线阅读，无需账号或 API Key。

网页展示的是整理好的场景参考；实际 AI 对话陪练由你使用的 AI 工具加载 Skill 后完成。

## 安装 Skill

下载并解压 [social-conversation.zip](downloads/social-conversation.zip)，将完整的 `social-conversation` 文件夹放进所用工具支持的 Skill 目录。Codex 用户可使用 `~/.codex/skills/`；其他工具按其说明导入。

例如：

> 用人情世故对话陪练帮我处理：周五下班前，领导让我周末来公司。我没有值班安排，也没答应待命。我想拒绝，又不想编理由。先给我一句能发微信的回复。

> 朋友又来借钱，我不想借，也不想编理由。如果他说“你有钱就是不愿意帮”，我怎么接？

> 现在你扮演领导，说“别人都能来，怎么就你特殊”。一次只说一句，等我回答后继续。

- 法律、医疗等专业判断应结合所在地、时间与事实由相关专业人员作出。国外机构材料只参考一般沟通原则，不套用其法律。

## 维护

数据位于 `data/cases.json` 和 `data/sources.json`，页面模板位于 `templates/page.html`。修改后执行：

```sh
python3 scripts/build.py
python3 scripts/check.py
```

构建仅依赖 Python 标准库，会生成网页、完整指南、按主题拆分的 Skill 参考资料和下载包。
