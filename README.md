# 职场人情世故指南

**103 个职场场景 · 12 个主题 · 两轮回应 · 可直接使用的 AI Skill**

领导周五通知周末加班，怎么回？自己的成果被另一个部门抢走，怎么说？饭局上被劝酒，怎样把边界讲清楚？

这里把难开口的问题拆成：**先确认什么 → 第一句怎么说 → 被反问后怎么接 → 接下来做什么 → 哪些情况不能硬套**。

[阅读完整指南](GUIDE.md) · [下载 Skill](downloads/workplace-conversation.zip) · [查看来源](SOURCES.md)

## 使用网页

下载仓库后直接打开 `index.html`。页面支持关键词检索、12 类主题筛选、内容依据筛选、分页阅读、复制回应与复制给 AI 的问题。全部内容可离线阅读，无需账号或 API Key。

网页展示的是整理好的场景参考；实际 AI 对话陪练由你使用的 AI 工具加载 Skill 后完成。

## 安装 Skill

下载并解压 [workplace-conversation.zip](downloads/workplace-conversation.zip)，将完整的 `workplace-conversation` 文件夹放进所用工具支持的 Skill 目录。Codex 用户可使用 `~/.codex/skills/`；其他工具按其说明导入。

例如：

> 用职场对话陪练帮我处理：周五下班前，领导让我周末来公司。我没有值班安排，也没答应待命。我想拒绝，又不想编理由。先给我一句能发微信的回复。

> 现在你扮演领导，说“别人都能来，怎么就你特殊”。一次只说一句，等我回答后继续。

## 内容与依据

| 主题 | 覆盖问题 |
|---|---|
| 加班与边界 | 临时加班、消息待命、优先级、职责外请求 |
| 成果与责任 | 抢功、署名、甩锅、版本记录、责任澄清 |
| 向上沟通 | 模糊指令、反对意见、多头管理、坏消息 |
| 绩效与回报 | 模糊反馈、晋升、调薪、目标与支持 |
| 同事与协作 | 搭便车、反复求助、信息同步、个人边界 |
| 饭局与关系 | 劝酒、座次、隐私问题、随礼与关系 |
| 求职与入职 | 岗位不符、收费风险、入职支持、试用目标 |
| 远程与会议 | 在线边界、会议效率、异步协作 |
| 客户与对外 | 范围蔓延、不合理承诺、投诉与授权 |
| 管理与带人 | 反馈、授权、资源、员工求助与离职 |
| 尊重与安全 | 羞辱排斥、骚扰、安全、数据与压力 |
| 离职与交接 | 通知、挽留、交接、签字、背调与作品集 |

- **49 条资料启发**：以机构资料、公开案例、社区讨论或问答检索线索为选题依据。16 个来源条目逐一标注了核查状态与使用范围。
- **54 条原创建议**：基于职责、事实、边界与后续动作编写，没有声称是互联网真实事件。
- 所有话术和场景细节均为独立编写。社区叙述未独立核实；3 个来源只读到检索摘要，不冒充正文研究。来源并不保证话术有效。
- 法律、医疗等专业判断应结合所在地、时间与事实由相关专业人员作出。国外机构材料只参考一般沟通原则，不套用其法律。

灵感起点是 [HowToGetAlong](https://github.com/kkk-bot/HowToGetAlong)。本仓库未复制、打包或重新授权其正文，使用独立编写的职场内容与页面代码。

## 维护

数据位于 `data/cases.json` 和 `data/sources.json`，页面模板位于 `templates/page.html`。修改后执行：

```sh
python3 scripts/build.py
python3 scripts/check.py
```

构建仅依赖 Python 标准库，会生成网页、完整指南、按主题拆分的 Skill 参考资料和下载包。
