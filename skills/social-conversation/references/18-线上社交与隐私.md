# 线上社交与隐私

## 144 · 朋友把我的丑照发到网上，我想让他删

**情境**：不是所有合照都愿意公开。

**开口之前**：明确是哪张、在哪个平台，不顺带羞辱对方拍照水平。

**可以这样说**：这张照片我不想公开，请帮我删掉。以后发有我的照片前先问我一下。

**对方说**：有什么关系，又没人看。

**下一句**：有没有人看不是重点，我不想公开这张照片，请尊重这个决定。

**接下来做什么**：先直接提出请求，必要时使用平台隐私申诉渠道。

**判断边界**：无法保证转发副本全部消失，也不以曝光对方隐私回击。

**使用判断 · C 慎重处理**：可提出删除请求；无法保证全部转发副本消失。

**依据**：原创建议，未声称对应某个真实事件。

## 145 · 熟人把我的联系方式给别人，没问过我

**情境**：突然收到陌生业务邀约。

**开口之前**：是否原来已同意某种范围的介绍？明确范围更容易执行。

**可以这样说**：以后转我的联系方式前请先问我，这次也请和对方说明，我还没有答应联系或帮忙。

**对方说**：我是在给你介绍机会。

**下一句**：谢谢你想着我，不过机会是否合适需要我自己判断，联系方式也请先征得同意。

**接下来做什么**：向新联系人说明可接受的联系渠道与目的，必要时拒绝。

**判断边界**：不公开对方号码作反击。

**使用判断 · C 慎重处理**：先明确联系方式的分享范围，不公开号码反击。

## 149 · 家族群转发未经核实的消息，想提醒

**情境**：不想当众说长辈“没文化”。

**开口之前**：自己是否也只是凭感觉？不确定时明确说不确定。

**可以这样说**：这条信息我还没看到可靠出处，我们先别继续转发，等核到原始来源再判断。

**对方说**：那么多人都在传，怎么会是假的？

**下一句**：传播多不等于已经核实，我先找原始出处；没有证据前我们都留一点余地。

**接下来做什么**：查原始发布者、时间和完整上下文，避免另转一条未经核实的反驳。

**判断边界**：健康、法律、财务信息需要当前权威来源，不作随口断言。

**使用判断 · C 慎重处理**：涉及健康、法律或财务的消息，先核对当前权威来源。

**依据**：原创建议，未声称对应某个真实事件。
