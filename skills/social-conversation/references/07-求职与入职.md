# 求职与入职

## 56 · 面试岗位与入职工作差很多

**情境**：承诺做产品，入职后主要安排销售。

**开口之前**：比对招聘信息、书面约定和实际安排，不只凭记忆。

**可以这样说**：我想核对一下岗位职责，目前安排与面试沟通有明显差异。请说明后续主要工作和考核标准。

**对方说**：新人先服从安排。

**下一句**：我愿意了解业务，也需要确认这是短期轮岗还是长期岗位变化。

**接下来做什么**：请HR和负责人明确范围、期限与培训支持。

**判断边界**：岗位变更的法律问题另行核实，不把口头解释视为已解决。

**使用判断 · C 慎重处理**：岗位、合同与权益问题，需核对书面约定及适用规则。

## 57 · 面试被追问结婚生育计划

**情境**：担心不回答就失去机会。

**开口之前**：记录实际问题与岗位要求，不立即推断所有动机。

**可以这样说**：我能满足这个岗位明确的工作要求。个人婚育安排不影响我对职责的理解，我们可以具体聊岗位安排。

**对方说**：我们只是想知道你能不能稳定干。

**下一句**：我可以说明可到岗时间和工作计划，但不希望以私人安排替代能力评估。

**接下来做什么**：评估单位文化与个人接受程度，必要时咨询正规渠道。

**判断边界**：就业歧视是否成立需结合事实和适用规则判断。

**使用判断 · C 慎重处理**：岗位、合同与权益问题，需核对书面约定及适用规则。

## 58 · 收到口头offer，对方催我马上辞职

**情境**：书面条件一直没有确认。

**开口之前**：录用是否附背景审查等条件，哪些尚未完成？

**可以这样说**：我很期待加入，但需要先确认书面岗位、薪酬、到岗时间和录用条件，再安排离职。

**对方说**：这么不信任我们？

**下一句**：这是为了双方安排明确，避免到岗前产生误解，不是针对贵公司。

**接下来做什么**：等关键条件确认后再做不可逆的工作变动。

**判断边界**：书面offer也不等于任何风险都消失。

**使用判断 · C 慎重处理**：岗位、合同与权益问题，需核对书面约定及适用规则。

**依据**：原创建议，未声称对应某个真实事件。

## 59 · 入职第一周没人带，也没有账号

**情境**：怕闲着显得不主动。

**开口之前**：是否有入职计划、职责说明和安全培训？

**可以这样说**：我已梳理目前能做的准备，接下来需要X账号和一个业务联系人，才能开始第一项交付。

**对方说**：你先自己熟悉熟悉。

**下一句**：好的，我先看现有资料；能否帮我确认资料入口和本周最需要掌握的事情？

**接下来做什么**：列最小阻塞清单，主动约简短对齐，不申请超出职责的权限。

**判断边界**：不借用他人账号绕过入职流程。

## 60 · 试用期目标从未说清

**情境**：快到考核才知道标准。

**开口之前**：目标是否与岗位职责一致，是否有书面说明？

**可以这样说**：我想尽早确认试用期要证明的几项能力、交付物和反馈节点，避免到最后才发现理解不同。

**对方说**：看综合表现，不用那么细。

**下一句**：综合表现也可以用几个具体例子来对齐。我先拟一版目标，请您修正。

**接下来做什么**：定期记录反馈和成果，及时请求改进支持。

**判断边界**：试用期权利与程序需核实，不承诺靠留记录就一定通过。

**使用判断 · C 慎重处理**：岗位、合同与权益问题，需核对书面约定及适用规则。

## 61 · 入职培训突然变成收费课程

**情境**：对方说先交钱才安排工作。

**开口之前**：岗位是否真实，收费方和用人单位是否一致？

**可以这样说**：请先提供招聘主体、岗位关系、收费依据和完整书面材料，我不会在没核实前付款。

**对方说**：名额马上没有了。

**下一句**：我需要先核实信息，不能因为催促就作付款决定。

**接下来做什么**：通过独立渠道核实企业和招聘信息，保留必要往来记录。

**判断边界**：遇疑似欺诈应寻求正规帮助，不靠继续付费验证真伪。

**使用判断 · C 慎重处理**：涉及收费与疑似欺诈，不继续付费来验证真伪。

## 62 · 面试要求做完整商业方案当作业

**情境**：怕被免费拿走成果。

**开口之前**：作业规模是否合理，是否明显对应正在执行的商业项目？

**可以这样说**：我可以提供方法框架或有限样稿。完整可直接落地的方案，需要先确认使用范围与评估安排。

**对方说**：其他候选人都交了。

**下一句**：我理解评估需要，也愿意展示能力；涉及完整成果的部分，我希望明确双方边界。

**接下来做什么**：限定投入、去除敏感客户信息，保留自己提交的版本。

**判断边界**：不能保证限制使用的说明一定获得接受或法律保护。

## 63 · 试用期收到模糊的淘汰暗示

**情境**：只被说“不太合适”，不知道该怎么改。

**开口之前**：是反馈、正式决定，还是传闻？

**可以这样说**：能否明确具体差距、实际例子和可改进的时间安排？我希望知道接下来如何达到要求。

**对方说**：这些不方便细说。

**下一句**：那请至少确认当前评估结论和后续流程，我也需要据此安排。

**接下来做什么**：保存与本人相关的正式通知，必要时找HR核对。

**判断边界**：涉及终止劳动关系时另求专业支持，不替任何一方判断合法性。

**使用判断 · C 慎重处理**：岗位、合同与权益问题，需核对书面约定及适用规则。
